## Tool Description

Grounded deep search via Gemini API with Google Search. Performs multi-phase research: initial search → decompose into follow-up questions → parallel follow-up searches. Creates interlinked objects in the space: a collection containing an overview page, sub-topic pages, and source bookmarks. Use for research that needs sub-topic decomposition and a durable, structured write-up. Not for simple factual lookups (use webSearch for those).

## Tool Schema

### research(question, opts?) [mutator]

Perform grounded web research via Gemini. Creates a collection with overview page, follow-up sub-pages, and source bookmarks.

**Input:**
- `question` (string, required) — the research question
- `opts` (object, optional):
  - `model` (string) — Gemini model ID (default: "gemini-2.5-flash")
  - `systemPrompt` (string) — override the default research system prompt

**Output:** Object with:
- `ok` (boolean) — whether the research succeeded
- `collectionId` (string) — ID of the research collection
- `collectionName` (string) — name of the collection (generated by LLM)
- `overviewPageId` (string) — ID of the main overview page
- `overviewPageName` (string) — name of the overview page
- `subPages` (array) — follow-up pages: `[{ id, name }]`
- `bookmarks` (array) — source bookmarks: `[{ id, name, url }]`
- `pageId` (string) — alias for overviewPageId (backward compat)
- `pageName` (string) — alias for overviewPageName
- `answer` (string) — initial Gemini answer text
- `sources` (array) — deduplicated sources: `[{ url, title, domain }]`
- `searchQueries` (string[]) — search queries from initial call
- `timing` (object) — `{ totalMs, phase1Ms, phase2Ms, phase3Ms }`
- `usage` (object) — token counts from initial call

Typical latency: ~50 seconds (23s initial + 2s decompose + 23s follow-ups + 1s object creation).
Sends progress updates to the chat (via `anyHelper.sendChatMessage`) at each phase.

**Example:**
```js
var result = geminiDeepSearch.research("What are the main CRDT implementations used in collaborative editing?");
result.collectionId  // "bafyrei..." — collection with all research artifacts
result.overviewPageId // "bafyrei..." — main overview page
result.subPages      // [{ id: "...", name: "How does Yjs handle..." }, ...]
result.bookmarks     // [{ id: "...", name: "crdt.tech", url: "..." }, ...]
```
